# TG WS Proxy 2.1.3

- Bound the best-effort drain after an invalid MTProto handshake to 64 KiB and 10 seconds total, including connections using Fake TLS.
- Use the original DC203 number for Cloudflare WebSocket and HTTP/2 routes, matching Flowseal. Direct Telegram WebSocket aliases are unchanged.
- Isolate the first WS and TCP relay writes from connection establishment so saturated dial slots cannot prevent an already connected socket from sending its initialization. Pool-hit timing is measured separately.
- Added a confirmed reset-to-defaults action in Settings. It restores settings and appearance, creates a new proxy secret, and restarts a running proxy. Add the new link in Telegram; diagnostic logs are retained.

Regression tests cover drain limits, DC203 host selection and relay initialization under dial saturation. The release workflow runs JVM tests and Android lint before building the APK. Real-device Telegram interoperability, including DC203, and the settings-reset UI still require device validation.

## По-русски

- Чтение после неверного рукопожатия MTProto ограничено 64 КиБ и 10 секундами суммарно, в том числе при использовании Fake TLS.
- Маршруты Cloudflare WebSocket и HTTP/2 используют исходный номер DC203, как в Flowseal. Адреса прямого WebSocket к Telegram не изменены.
- Отправка первого пакета по WS и TCP отделена от установки соединений: занятые слоты подключения не мешают инициализации уже открытого сокета. Время получения соединения из пула измеряется отдельно.
- В настройках появился сброс к значениям по умолчанию с подтверждением. Он сбрасывает настройки и оформление, создаёт новый секрет и перезапускает работающий прокси. Добавьте новую ссылку в Telegram; журнал диагностики сохраняется.

Регрессионные тесты проверяют лимиты чтения, выбор адресов DC203 и инициализацию соединения при занятых слотах подключения. Перед сборкой APK CI запускает JVM-тесты и Android lint. Работа с Telegram на устройстве, включая DC203, и интерфейс сброса настроек требуют отдельной проверки.
