# TG WS Proxy 2.0.0

## Refreshed Interface

- New connection-link app icon, monochrome notification icon, and Quick Settings tile artwork.
- Tabler outline icons throughout the interface, replacing the Material icon library with a small bundled subset.
- Telegram-inspired light and dark palettes, coordinated system bars, improved contrast, and optional Material You colors.
- Combined proxy status and controls, a compact proxy-link row with full-link viewing and copying, and clearer uptime labeling.
- Statistics grouped into connections, transport, traffic, pool hits, and errors. Data sizes now separate values from units.
- Grouped settings, full-row switches, and full-width theme and ping-interval choices that accommodate longer labels and larger text.
- Centered content with a maximum width on larger displays.

## Remembers Your Last Choice

- Removed the separate start-at-boot setting. Starting the proxy now saves the intention to keep it enabled; after device startup, the app attempts to restore it.
- Explicitly stopping the proxy from the app, notification, or Quick Settings cancels restoration, even if the runtime is already stopped.
- Process death, runtime failure, and internal restarts do not clear the saved intention.
- If startup fails, Retry start and Stop remain available so restoration can be retried or cancelled.
- Existing installations initialize this behavior from the former start-at-boot preference. New Start and Stop actions then determine it.
- Android force-stop, background restrictions, and manufacturer policies can still prevent restoration.

## Help and Project Information

- Reorganized built-in help into expandable topics, with Quick start open initially.
- Updated English and Russian explanations of routing, power settings, diagnostics, connection statistics, and troubleshooting.
- Added explicit transport-security limits and an explanation of in-app update verification.
- Updated About with the actual app icon, project credits, and Tabler attribution.
- Refreshed the README with current screenshots and a shorter setup guide; historical release notes now live in `release-notes/`.

## Reliability

- User commands are serialized and persisted independently of screen, tile, and service lifetimes.
- Boot recovery and sticky service recreation check saved intent before starting the runtime.
- Runtime ownership checks prevent obsolete startup work from restoring a notification after Stop or stopping a newer runtime during restart.
- Added tests for intent migration, command ordering, Tabler vector parsing, and byte formatting.

## Verification

- JVM unit tests, Android lint, debug builds, and R8-minified release builds passed with JDK 17.
- Actual reboot recovery, sticky service recreation, rapid Start/Stop sequences, and manufacturer background restrictions still require device validation.
- This remains a Telegram proxy, not a device-wide VPN. Proxy WebSocket TLS certificate verification remains intentionally disabled; Telegram message encryption is separate.
