# TG WS Proxy 2.1.2

- Cloudflare and Workers can automatically try port 80 without TLS after a timeout, without changing the saved setting. Each fallback stage has an eight-second budget, so the proxy can reach TCP sooner. A known HTTP rejection does not trigger a downgrade.
- Upstream setup is cancelled when the local client disconnects. Direct WebSocket setup and the first WS/TCP relay write have deadlines; ordinary streaming is unchanged.
- Worker cooldowns now respect daily limits and temporary failures. Diagnostics include connection stages and timings without exposing endpoint addresses.

Transport changes are adapted from [Flowseal v1.12.0](https://github.com/Flowseal/tg-ws-proxy/tree/v1.12.0).

## По-русски

- После таймаута Cloudflare и Workers могут автоматически попробовать порт 80 без TLS. Сохранённая настройка не меняется. На каждый этап отведено до восьми секунд, чтобы быстрее перейти к TCP. Ответ с отказом HTTP сам по себе не отключает TLS.
- Если Telegram закрывает локальное соединение, прокси отменяет установку внешнего. Для прямого WebSocket и отправки первого пакета по WS/TCP добавлены дедлайны; передача данных после подключения не ограничена ими.
- Паузы для Workers учитывают суточные лимиты и временные ошибки. В журнал добавлены этапы и длительность подключения без раскрытия адресов.
