# TG WS Proxy 2.1.1

- Fixed APK certificate lookup for in-app updates on Android 9 and 10. The updater still requires a matching signing certificate and verifies the download checksum.
- Added a connection tip that suggests trying Cloudflare without TLS only after repeated Cloudflare failures leave no working route for the affected connection. The app never changes the setting automatically. Without TLS, Cloudflare uses port 80 and HTTP/2 is unavailable.

**If the in-app update fails:** download `tg-ws-proxy-2.1.1.apk` from this release and install it over your existing version without uninstalling, so your settings are kept.

## По-русски

- Исправлено чтение сертификата APK при обновлении из приложения на Android 9 и 10. Проверка подписи и контрольной суммы сохранена.
- При повторных сбоях Cloudflare и отсутствии рабочего маршрута приложение предлагает попробовать отключить TLS для Cloudflare. Настройка не меняется автоматически. Без TLS используется порт 80 и недоступен HTTP/2.

**Если обновление из приложения не устанавливается:** скачайте `tg-ws-proxy-2.1.1.apk` из этого релиза и установите поверх текущей версии, не удаляя приложение. Настройки сохранятся.
